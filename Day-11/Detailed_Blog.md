# Day 11: Anatomy of a Prompt (Detailed Blog)

## Introduction

Prompts are the instructions we give to large language models (LLMs) to get useful responses. Today, I explored what makes a good prompt and how different prompt structures affect model output.

## Coding Exercise
The code for today is available in the Day-11 folder as `prompt_anatomy_demo.py`. It sends several types of prompts to a local LLM (or OpenAI API if available), collects the responses, and generates an image (`prompt_output_comparison.png`) comparing the outputs.

## What Did I Learn?
- The structure, clarity, and context of a prompt are crucial for getting high-quality responses.
- Including examples and explicit instructions improves results.
- Visualizing outputs helps understand prompt engineering.

## Results
I ran the code and here’s what I found:
- Prompts with clear instructions and examples produced more accurate and relevant answers.
- The comparison image made it easy to see how small changes in wording can lead to big differences in output.
