# Day 12: Prompt Engineering Basics (Detailed Blog)

## Introduction

Prompt engineering is the art of crafting effective instructions for large language models (LLMs). Today, I explored prompt templates, temperature settings, and few-shot learning to see how they impact model output.

## Coding Exercise
The code for today is available in the Day-12 folder as `prompt_engineering_demo.py`. It sends several types of engineered prompts to a simulated LLM (or OpenAI API if available), collects the responses, and generates an image (`prompt_engineering_comparison.png`) comparing the outputs.

## What Did I Learn?
- Prompt templates and examples help guide LLMs to produce better results.
- Temperature settings control randomness and creativity in responses.
- Visualizing outputs helps understand prompt engineering strategies.

## Results
I ran the code and here’s what I found:
- Prompts with templates and examples produced more accurate and relevant answers.
- Adjusting temperature led to more creative or more deterministic outputs.
- The comparison image made it easy to see how prompt engineering affects LLM behavior.
