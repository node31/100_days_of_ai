Day 6: Your First AI Model (Detailed Blog)

Introduction

On Day 5, you set up your Python and Jupyter environment. Today, you’ll build your first AI model: a simple sentiment analysis classifier using Python and scikit-learn.

What is Sentiment Analysis?

Sentiment analysis is the process of determining whether a piece of text is positive, negative, or neutral. It’s widely used in business, social media, and customer feedback analysis.

Step-by-Step Guide

  1. Install scikit-learn

    Open your terminal and run:

    pip install scikit-learn

  2. Sample Data

    Create a small dataset:

    texts = [ "I love this product!", "This is the worst experience ever.", "Absolutely fantastic service.", "I am not happy with the quality." ] labels = [1, 0, 1, 0] # 1 = positive, 0 = negative

  3. Convert Text to Features

    python from sklearn.feature_extraction.text import CountVectorizer vectorizer = CountVectorizer() X = vectorizer.fit_transform(texts)

  4. Train a Model

    python from sklearn.linear_model import LogisticRegression model = LogisticRegression() model.fit(X, labels)

  5. Test the Model

    python test_texts = ["I enjoyed this!", "Terrible service."] X_test = vectorizer.transform(test_texts) predictions = model.predict(X_test) print(predictions) # [1 0]
