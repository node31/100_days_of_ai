Now that your environment is set up, it’s time to build your very first AI model. Today, we’ll create a simple machine learning model to classify text as positive or negative (sentiment analysis) using Python and scikit-learn.

WHY START WITH SENTIMENT ANALYSIS?
Sentiment analysis is a classic beginner project that shows how AI can extract meaning from text. It’s used in social media monitoring, customer feedback, and more.

WHAT YOU’LL DO
• Load a small dataset of text and labels (positive/negative)
• Convert text to features using CountVectorizer
• Train a logistic regression model
• Test the model on new examples
