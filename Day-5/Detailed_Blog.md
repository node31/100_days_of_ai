# Day 5: Setting Up Your Environment (Detailed Blog)

## Introduction

On Day 4, we learned about language models and their role in modern AI. Today, we’ll set up your development environment so you can start building and experimenting with AI code.

## Why Environment Setup Matters
A good environment helps you:
- Run code without errors
- Install and manage libraries easily
- Organize your projects
- Collaborate with others

## Essential Tools
- **Python:** The most popular language for AI and ML. Download from python.org.
- **Jupyter Notebook/JupyterLab:** Interactive coding environments for data science and AI. Install via pip or Anaconda.
- **pip:** Python’s package manager for installing libraries.
- **Git:** Version control for tracking changes and collaborating.

## Optional Tools
- **Anaconda:** Simplifies managing Python environments and packages.
- **VS Code:** A powerful, free code editor with great Python support.

## Step-by-Step Setup
1. **Install Python:** Download and install Python 3.8+ from python.org.
2. **Install Jupyter:** Run `pip install notebook` or install Anaconda (which includes Jupyter).
3. **Test Jupyter:** Open a terminal and run `jupyter notebook` to launch.
4. **Install Git:** Download from git-scm.com and follow the instructions.
5. **(Optional) Install VS Code:** Download from code.visualstudio.com.
