DAY 5: SETTING UP YOUR ENVIRONMENT | 100 DAYS OF AI

Welcome to Day 5 of my 100 Days of AI journey!

Now that we’ve covered the basics of AI, machine learning, deep learning, and language models, it’s time to get hands-on. Today, we’ll set up your environment so you’re ready to build and experiment with AI tools and code.

WHY IS ENVIRONMENT SETUP IMPORTANT?
A well-configured environment makes it easy to run code, install libraries, and avoid common errors. It’s the foundation for all your AI projects.

WHAT YOU’LL NEED
• Python (recommended: version 3.8 or higher)
• Jupyter Notebook or JupyterLab
• pip (Python package manager)
• Git (for version control)

OPTIONAL BUT USEFUL
• Anaconda (for managing Python environments)
• VS Code or another code editor

TODAY’S REFLECTION
Think about how having the right tools can make learning and building much smoother. A good setup saves time and frustration!
